# 🚀 Postiz Deployment (Docker + Render Free)

Deploy **Postiz** to Render with Docker Compose — free and fully functional.

## Steps

### 1️⃣ Upload to GitHub
- Create a new repository (example: `postiz-on-render`).
- Upload the 3 files:
  - `docker-compose.yml`
  - `.env`
  - `README.md`

### 2️⃣ Deploy to Render
1. Go to [Render.com](https://render.com)
2. Click **New + → Web Service**
3. Connect GitHub → choose your repo
4. Select:
   - Runtime: **Docker**
   - Region: (closest to you)
   - Plan: **Free**
5. Wait for build to finish (~2–3 minutes)
